## 📚 Indexer Base

Base indexer works with basic information about blocks 🧱, transactions 💸, account 👤 & access keys 🔑

### Config

```
DATABASE_URL=
NETWORK=mainnet
BASE_INDEXER_KEY=
NEARDATA_URL=https://mainnet.neardata.xyz
NEARDATA_AUTHORIZATION=Bearer <key> # Optional
NEARDATA_API_KEY=                 # Optional alternative to authorization header
NEARDATA_CONCURRENCY=auto

# Optional
DATABASE_CA=
DATABASE_CERT=
DATABASE_KEY=
BASE_START_BLOCK=
SENTRY_DSN=
```
